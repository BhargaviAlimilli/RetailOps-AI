# RetailOps AI

A retail operations application being built incrementally for a senior full-stack engineering demonstration: React/TypeScript, FastAPI, PostgreSQL, and a grounded AI workspace with explicit human approval for business actions.

This repository is under active implementation. See [progress](docs/IMPLEMENTATION_PROGRESS.md) for verified functionality and blockers, and the [implementation plan](docs/IMPLEMENTATION_PLAN.md) for upcoming milestones. Planned features are not claimed as complete.
